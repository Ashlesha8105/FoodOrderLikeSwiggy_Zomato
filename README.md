🍔 FoodOrderLikeSwiggy_Zomato

A Smart Food Ordering System inspired by popular food delivery platforms like Swiggy and Zomato. This web application allows customers to browse food items, place orders, and track their orders, while administrators manage food items and customer orders.

🚀 Features

👤 Customer Panel
Customer registration and login
Browse food items by category
View food images, descriptions, and prices
Add food items to the cart
Place food orders
View order history
Track order status

🔐 Admin Panel
Admin login
Manage food items and categories
View customer orders
Update order status
Manage food ordering operations

🛠️ Technologies Used
Frontend: HTML, CSS, Bootstrap, JavaScript
Backend: Python, Flask
Database: SQLite
Deployment: Render
Version Control: Git and GitHub

🎯 Project Objective
The objective of this project is to develop a user-friendly online food ordering platform that simplifies food browsing, cart management, order placement, and order tracking while providing administrators with tools to manage food items and orders.
